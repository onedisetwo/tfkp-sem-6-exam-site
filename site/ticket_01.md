**Формулировка в программе:** Функции многих переменных: от уравнений Коши-Римана к кратной интегральной формуле Коши.

> **Покрытие лекциями:** есть в лекциях · **Источник:** С6 §2.1.1–2.1.2 · **Опирается на:** [A2](00_base.html#A2), [A3](00_base.html#A3), [B3](00_base.html#B3), [B4](00_base.html#B4), [B6](00_base.html#B6)

## 1. Краткий ответ на 1 минуту

::: short
Функция $f:D\to\mathbb C$, $D\subset\mathbb C^n$, называется **голоморфной**, если она $\mathbb R$-дифференцируема и $\bar\partial f\equiv0$, то есть $\dfrac{\partial f}{\partial\bar z_j}=0$ для всех $j$ (условия Коши–Римана по каждой переменной). Тогда $f$ голоморфна по каждой переменной при фиксированных остальных.

Если $f$ голоморфна в произведении областей $D=D_1\times\dots\times D_n$ (с непрерывным выходом на границу), то, применяя одномерную формулу Коши **по очереди к каждой переменной** и пользуясь теоремой Фубини, получаем **кратную формулу Коши**:
$$f(z)=\frac1{(2\pi i)^n}\int_{\partial D_1\times\dots\times\partial D_n}\frac{f(\zeta_1,\dots,\zeta_n)}{(\zeta_1-z_1)\cdots(\zeta_n-z_n)}\,d\zeta_1\dots d\zeta_n .$$
Для полидиска интегрирование идёт не по всей границе, а по **остову** $\operatorname{Sk}\Delta=\{\lvert\zeta_j-a_j\rvert=r_j\}$ — это $n$-мерный тор, а граница полидиска имеет вещественную размерность $2n-1$.
:::

## 3. Определения и формулировки

**Обозначения (С6 §2.1.1).** $z=(z_1,\dots,z_n)\in\mathbb C^n$, $z_j=x_j+iy_j$, $\lvert z\rvert^2=\lvert z_1\rvert^2+\dots+\lvert z_n\rvert^2$. Шар $B(a,r)=\{z:\lvert z-a\rvert<r\}$.

**Определение (полидиск).** Область
$$\Delta_r(a)=\{z:\ \lvert z_j-a_j\rvert<r_j,\ j=1,\dots,n\},\qquad a\in\mathbb C^n,\ r\in(\mathbb R_+)^n,$$
называется *полидиском*. Это декартово произведение одномерных кругов. Подмножество границы $\{\lvert z_j-a_j\rvert=r_j\ \forall j\}$ называется *остовом* полидиска и обозначается $\operatorname{Sk}\Delta$.

**Операторы (С6 (1)–(3)).**
$$\frac{\partial}{\partial z_j}:=\frac12\Big(\frac{\partial}{\partial x_j}-i\frac{\partial}{\partial y_j}\Big),\qquad \frac{\partial}{\partial\bar z_j}:=\frac12\Big(\frac{\partial}{\partial x_j}+i\frac{\partial}{\partial y_j}\Big),$$
$$\partial f:=\sum_j f_{z_j}\,dz_j,\qquad \bar\partial f:=\sum_j f_{\bar z_j}\,d\bar z_j .$$
Если $f$ $\mathbb R$-дифференцируема, то
$$df=\sum_{j=1}^n\big(f_{x_j}dx_j+f_{y_j}dy_j\big)=\sum_{j=1}^n\big(f_{z_j}dz_j+f_{\bar z_j}d\bar z_j\big)=\partial f+\bar\partial f .$$

**Определение (голоморфность, С6 §2.1.1).** Функция $f$ называется *голоморфной в области $D$*, если $\bar\partial f\equiv0$ всюду в $D$. Множество таких функций — $O(D)$.

Расписав $\dfrac{\partial f}{\partial\bar z_j}=0$ для $f=u+iv$, получаем условия Коши–Римана по каждой переменной:
$$\frac{\partial u}{\partial x_j}=\frac{\partial v}{\partial y_j},\qquad\frac{\partial u}{\partial y_j}=-\frac{\partial v}{\partial x_j},\qquad j=1,\dots,n .$$

**Наблюдение.** Голоморфная функция голоморфна по каждому аргументу при фиксированных остальных, так как $f_{\bar z_j}=0$ при всех $j$.

::: warn
⚠️ **Про определение.** В С6 голоморфность определена для $\mathbb R$-дифференцируемой $f$ условием $\bar\partial f\equiv0$. В доказательстве формулы Коши дальше применяется теорема Фубини со словами «под интегралом хорошая функция», то есть **молча используется непрерывность** $f$ на замыкании. На экзамене стоит сказать об этом вслух: $\mathbb R$-дифференцируемая функция непрерывна, а на компактном остове непрерывная функция ограничена, поэтому Фубини применима.
:::

**Теорема (кратная формула Коши, С6 (6)).** Пусть $D=D_1\times\dots\times D_n$, где $D_j\subset\mathbb C$ — ограниченные области с кусочно-гладкими границами, $f\in O(D)$ и $f$ непрерывна на $\overline D$. Тогда для любого $z\in D$
$$f(z)=\frac1{(2\pi i)^n}\int_{\partial D_1\times\dots\times\partial D_n}\frac{f(\zeta_1,\dots,\zeta_n)}{\prod_{j=1}^n(\zeta_j-z_j)}\,d\zeta,\qquad d\zeta=d\zeta_1\dots d\zeta_n .$$
Для полидиска $\Delta=\Delta_r(a)$ с $\overline\Delta\subset D$:
$$f(z)=\frac1{(2\pi i)^n}\int_{\operatorname{Sk}\Delta}\frac{f(\zeta)\,d\zeta}{(\zeta_1-z_1)\cdots(\zeta_n-z_n)},\qquad z\in\Delta .$$

**Замечание (С6 (7)–(8)): голоморфная $n$-форма замкнута.** Для $f\in O(D)$ форма $\omega=f\,dz_1\wedge\dots\wedge dz_n$ удовлетворяет $d\omega=0$, и по формуле Стокса $\int_{\partial\sigma}\omega=\int_\sigma d\omega=0$ для любой $(n+1)$-мерной цепи $\sigma$ в $D$. Это многомерная теорема Коши ([Билет 6](ticket_06.html)).

## 4. Доказательства

### 4.1 Скелет доказательства

::: skeleton
1. Фиксируем $z_2,\dots,z_n$: функция $\zeta_1\mapsto f(\zeta_1,z_2,\dots,z_n)$ голоморфна в $D_1$, пишем одномерную формулу Коши по $\zeta_1$.
2. Для каждой точки $\zeta_1\in\partial D_1$ функция $\zeta_2\mapsto f(\zeta_1,\zeta_2,z_3,\dots)$ голоморфна в $D_2$; подставляем её формулу Коши под интеграл.
3. Повторяем для $z_3,\dots,z_n$: получаем повторный интеграл по $\partial D_1,\dots,\partial D_n$.
4. Подынтегральная функция непрерывна на компакте $\partial D_1\times\dots\times\partial D_n$, по Фубини повторный интеграл равен кратному.
5. Замечание: $d(f\,dz_1\wedge\dots\wedge dz_n)=0$, так как $df$ содержит только $dz_j$, а $dz_j\wedge dz_j=0$.
:::

### 4.2 Полное доказательство

**Шаг 0. Голоморфность по каждой переменной.** Если $\bar\partial f\equiv0$, то при фиксированных $z_2,\dots,z_n$ функция $g(\zeta_1)=f(\zeta_1,z_2,\dots,z_n)$ $\mathbb R$-дифференцируема и $\partial g/\partial\bar\zeta_1=f_{\bar z_1}=0$, то есть $g$ голоморфна в $D_1$ (по [предложению 1.2 из С5](00_base.html#A2)). То же для любой переменной.

*Зачем:* всё доказательство — многократное применение одномерной теоремы, а она требует голоморфности по одной переменной.

**Шаг 1. Формула Коши по первой переменной.** Для $z\in D$ по одномерной формуле Коши ([B4](00_base.html#B4)):
$$f(z)=\frac1{2\pi i}\int_{\partial D_1}\frac{f(\zeta_1,z_2,\dots,z_n)}{\zeta_1-z_1}\,d\zeta_1 .\tag{4}$$
*Зачем:* выразили $f(z)$ через значения на «границе по первой координате».

**Шаг 2. Формула Коши по второй переменной.** Для каждой $\zeta_1\in\partial D_1$ функция $\zeta_2\mapsto f(\zeta_1,\zeta_2,z_3,\dots,z_n)$ голоморфна в $D_2$ и непрерывна на $\overline D_2$. (Здесь нужна голоморфность при $\zeta_1$ на границе $D_1$: она следует из того, что $f$ голоморфна в окрестности $\overline D$, либо из непрерывности на $\overline D$ предельным переходом $\zeta_1\to\partial D_1$. В С6 этот момент не обсуждается.) Поэтому
$$f(\zeta_1,z_2,\dots,z_n)=\frac1{2\pi i}\int_{\partial D_2}\frac{f(\zeta_1,\zeta_2,z_3,\dots,z_n)}{\zeta_2-z_2}\,d\zeta_2 .$$
Подставляем в (4):
$$f(z)=\frac1{(2\pi i)^2}\int_{\partial D_1}\Bigg(\int_{\partial D_2}\frac{f(\zeta_1,\zeta_2,z_3,\dots,z_n)}{(\zeta_1-z_1)(\zeta_2-z_2)}\,d\zeta_2\Bigg)d\zeta_1 .\tag{5}$$
*Зачем:* убрали зависимость от $z_2$ внутри $f$, заменив её интегралом по границе по второй координате.

**Шаг 3. Индукция.** Повторяя шаг 2 для $z_3,\dots,z_n$, получаем повторный интеграл
$$f(z)=\frac1{(2\pi i)^n}\int_{\partial D_1}\!\!\dots\int_{\partial D_n}\frac{f(\zeta_1,\dots,\zeta_n)}{\prod_j(\zeta_j-z_j)}\,d\zeta_n\dots d\zeta_1 .$$
*Зачем:* теперь $f$ под интегралом берётся только в точках, где **все** координаты на границах.

**Шаг 4. Фубини.** При фиксированном $z\in D$ знаменатель $\prod(\zeta_j-z_j)$ отделён от нуля на компакте $\partial D_1\times\dots\times\partial D_n$ (ведь $z_j\notin\partial D_j$), а $f$ на нём непрерывна. Значит, подынтегральная функция непрерывна на компакте, и повторный интеграл равен кратному интегралу по $\partial D_1\times\dots\times\partial D_n$. Получаем формулу (6). ∎

*Зачем:* повторный интеграл зависит от порядка, а кратный — нет; формула становится симметричной по переменным.

**Шаг 5 (замечание про $d\omega=0$).** Для $\omega=f\,dz_1\wedge\dots\wedge dz_n$ имеем $d\omega=df\wedge dz_1\wedge\dots\wedge dz_n$. Так как $f$ голоморфна, $df=\sum_jf_{z_j}dz_j$ (коэффициенты при $d\bar z_j$ нулевые). В каждом слагаемом $f_{z_j}dz_j\wedge dz_1\wedge\dots\wedge dz_n$ дифференциал $dz_j$ встречается дважды, а $dz_j\wedge dz_j=0$. Итак, $d\omega=0$, и по формуле Стокса $\int_{\partial\sigma}\omega=\int_\sigma d\omega=0$.

*Зачем:* это мост к [Билету 6](ticket_06.html) (теорема Коши–Пуанкаре): она обобщает одномерную теорему Коши так же, как формула (6) обобщает формулу Коши.

## 5. Интуиция и картинки

::: idea
**Почему остов, а не вся граница.** Одномерная формула Коши восстанавливает функцию по значениям на окружности. Применяя её по каждой координате, мы на каждом шаге отправляем на окружность **одну** координату. В конце на окружностях все $n$ координат, то есть точка $\zeta$ лежит на торе $\operatorname{Sk}\Delta=S^1\times\dots\times S^1$. Это $n$-мерное множество внутри $(2n-1)$-мерной границы. Голоморфной функции хватает «очень маленькой части» границы, чтобы восстановиться внутри.
:::

## 6. Пример / типовая задача с решением

::: example
**Задача.** Вычислите $I=\displaystyle\int_{\lvert\zeta_1\rvert=1,\ \lvert\zeta_2\rvert=2}\frac{e^{\zeta_1}\cos\zeta_2}{(\zeta_1-\tfrac12)(\zeta_2-1)}\,d\zeta_1d\zeta_2$.

**Решение.** Функция $f(\zeta_1,\zeta_2)=e^{\zeta_1}\cos\zeta_2$ голоморфна во всём $\mathbb C^2$. Интеграл идёт по остову бидиска $\Delta=\{\lvert z_1\rvert<1,\lvert z_2\rvert<2\}$, точка $z=(\tfrac12,1)$ лежит в $\Delta$. По кратной формуле Коши
$$I=(2\pi i)^2f\big(\tfrac12,1\big)=-4\pi^2e^{1/2}\cos1 .$$

**Вариант с производными.** Дифференцируя формулу Коши под знаком интеграла, получаем
$$\frac{\partial^{m_1+m_2}f}{\partial z_1^{m_1}\partial z_2^{m_2}}(z)=\frac{m_1!\,m_2!}{(2\pi i)^2}\int_{\operatorname{Sk}\Delta}\frac{f(\zeta)\,d\zeta}{(\zeta_1-z_1)^{m_1+1}(\zeta_2-z_2)^{m_2+1}} .$$
Например, $\displaystyle\int_{\lvert\zeta_1\rvert=\lvert\zeta_2\rvert=1}\frac{e^{\zeta_1\zeta_2}}{\zeta_1^2\zeta_2^2}d\zeta=(2\pi i)^2\cdot\frac{\partial^2 e^{z_1z_2}}{\partial z_1\partial z_2}\Big\vert_0=(2\pi i)^2\cdot1=-4\pi^2$.
:::

## 7. Частые дополнительные вопросы экзаменатора

- **Почему интеграл по остову, а не по всей границе?** Потому что формула получается применением одномерной формулы по каждой координате; на каждом шаге одна координата уходит на окружность. Остов — $n$-мерный тор, а граница полидиска $(2n-1)$-мерна.
- **Есть ли формула Коши для шара?** Не в таком виде: шар не является произведением кругов. Существует формула Бохнера–Мартинелли с интегралом по всей сфере, но её ядро не голоморфно по $z$. В курсе её нет.
- **Достаточно ли голоморфности по каждой переменной отдельно?** Да, это теорема Хартогса (С6, замечание в §2.2.5, без доказательства). Если дополнительно предположить непрерывность (лемма Осгуда), то это следует из нашего доказательства: шаги 1–4 используют только голоморфность по каждой переменной и непрерывность.
- **Где в доказательстве нужна непрерывность?** В теореме Фубини (шаг 4) и при переходе на границу (шаг 2).
- **Чему равно $\bar\partial$ от $\lvert z\rvert^2$?** $\bar\partial(z_1\bar z_1+\dots+z_n\bar z_n)=\sum z_jd\bar z_j\ne0$, функция не голоморфна.
- **Как отсюда получить формулу для производных?** Дифференцировать под знаком интеграла по $z$ (подынтегральная функция гладко зависит от $z$ при $z$ вдали от остова). См. раздел 6.

## 8. Типичные ошибки и ловушки

::: warn
- Писать $\dfrac1{2\pi i}$ вместо $\dfrac1{(2\pi i)^n}$.
- Интегрировать по всей границе полидиска $\partial\Delta$ вместо остова $\operatorname{Sk}\Delta$.
- Забыть, что $\overline\Delta$ должен лежать в области голоморфности (или нужна непрерывность до границы).
- Путать $\bar\partial f\equiv0$ (голоморфность) и $df=0$ (постоянство).
- Говорить, что голоморфность по каждой переменной «очевидно» влечёт голоморфность. Это теорема Хартогса, она трудная; очевидно только обратное.
:::

## 10. Самопроверка

::: quiz
1. Дайте определение голоморфной функции нескольких переменных.

    <details><summary>Ответ</summary>

    $f$ $\mathbb R$-дифференцируема в области $D\subset\mathbb C^n$ и $\bar\partial f=\sum_jf_{\bar z_j}d\bar z_j\equiv0$, то есть $\partial f/\partial\bar z_j=0$ для всех $j$.

    </details>

2. Что такое остов полидиска и какова его вещественная размерность?

    <details><summary>Ответ</summary>

    $\operatorname{Sk}\Delta=\{\lvert z_j-a_j\rvert=r_j,\ j=1..n\}$ — произведение $n$ окружностей, $n$-мерный тор. Вещественная размерность $n$ (а у границы полидиска $2n-1$).

    </details>

3. Напишите кратную формулу Коши для бидиска.

    <details><summary>Ответ</summary>

    $$f(z_1,z_2)=\frac1{(2\pi i)^2}\int_{\lvert\zeta_1-a_1\rvert=r_1}\int_{\lvert\zeta_2-a_2\rvert=r_2}\frac{f(\zeta_1,\zeta_2)}{(\zeta_1-z_1)(\zeta_2-z_2)}d\zeta_1d\zeta_2$$
    для $(z_1,z_2)$ внутри бидиска.

    </details>

4. Зачем в доказательстве теорема Фубини?

    <details><summary>Ответ</summary>

    Последовательное применение одномерной формулы даёт повторный интеграл. Чтобы записать его как кратный интеграл по произведению границ (и не зависеть от порядка), нужна Фубини; она применима, так как подынтегральная функция непрерывна на компакте.

    </details>

5. Почему $d(f\,dz_1\wedge\dots\wedge dz_n)=0$ для голоморфной $f$?

    <details><summary>Ответ</summary>

    $df=\sum f_{z_j}dz_j$ (нет $d\bar z_j$), и каждое слагаемое $f_{z_j}dz_j\wedge dz_1\wedge\dots\wedge dz_n$ содержит $dz_j$ дважды, а $dz_j\wedge dz_j=0$.

    </details>

6. Почему голоморфная функция голоморфна по каждой переменной при фиксированных остальных?

    <details><summary>Ответ</summary>

    При фиксированных $z_2,\dots,z_n$ функция $g(\zeta_1)=f(\zeta_1,z_2,\dots,z_n)$ $\mathbb R$-дифференцируема, и $\partial g/\partial\bar\zeta_1=f_{\bar z_1}=0$. По одномерному критерию (условия Коши–Римана) $g$ голоморфна в $D_1$; так же для любой другой переменной. Обратное утверждение — трудная теорема Хартогса.

    </details>

7. Голоморфна ли функция $f(z_1,z_2)=z_1\bar z_2$? Голоморфна ли она по каждой переменной?

    <details><summary>Ответ</summary>

    Нет: $f_{\bar z_2}=z_1\not\equiv0$, то есть $\bar\partial f=z_1\,d\bar z_2\ne0$. По $z_1$ при фиксированном $z_2$ она голоморфна (линейная функция $z_1\mapsto\bar z_2z_1$), а по $z_2$ при $z_1\ne0$ — нет. Голоморфность требует $f_{\bar z_j}=0$ сразу для всех $j$.

    </details>

8. В шаге 2 доказательства нужна голоморфность функции $\zeta_2\mapsto f(\zeta_1,\zeta_2,z_3,\dots,z_n)$ при $\zeta_1\in\partial D_1$. Откуда она берётся?

    <details><summary>Ответ</summary>

    Точка $\zeta_1$ лежит на границе $D_1$, поэтому голоморфность внутри $D$ здесь напрямую не применима. Она следует либо из голоморфности $f$ в окрестности $\overline D$, либо из непрерывности $f$ на $\overline D$: формула Коши по $\zeta_2$ верна при $\zeta_1$ внутри $D_1$ и сохраняется при предельном переходе $\zeta_1\to\partial D_1$. В С6 этот момент не обсуждается.

    </details>

9. Пусть $\Delta=\{\lvert z_1\rvert<1,\ \lvert z_2\rvert<1\}$. Чему равен $\int_{\operatorname{Sk}\Delta}\frac{d\zeta_1d\zeta_2}{(\zeta_1-2)\,\zeta_2}$?

    <details><summary>Ответ</summary>

    Нулю. Подставлять точку $(2,0)$ в кратную формулу Коши нельзя: она не лежит в $\Delta$. Считаем повторный интеграл (Фубини): $\int_{\lvert\zeta_1\rvert=1}\frac{d\zeta_1}{\zeta_1-2}=0$ по теореме Коши, так как $\frac1{\zeta_1-2}$ голоморфна в $\lvert\zeta_1\rvert\le1$. Значит, весь интеграл равен $0$, а не $(2\pi i)^2$.

    </details>

10. Как из кратной формулы Коши получить интегральную формулу для частных производных? Напишите её для $n=2$.

    <details><summary>Ответ</summary>

    Дифференцируем под знаком интеграла по $z_1$ и $z_2$: при $z\in\Delta$ точка отделена от остова, и подынтегральная функция гладко зависит от $z$.
    $$\frac{\partial^{m_1+m_2}f}{\partial z_1^{m_1}\partial z_2^{m_2}}(z)=\frac{m_1!\,m_2!}{(2\pi i)^2}\int_{\operatorname{Sk}\Delta}\frac{f(\zeta)\,d\zeta}{(\zeta_1-z_1)^{m_1+1}(\zeta_2-z_2)^{m_2+1}}$$
    При $z=a$ отсюда получаются коэффициенты ряда Тейлора (Билет 3).

    </details>
