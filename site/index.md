## Условные обозначения

| Пометка | Что значит |
|---|---|
| <span class="badge ok">есть в лекциях</span> | Билет изложен в конспекте лектора, формулировки взяты оттуда |
| <span class="badge part">частично</span> | Часть билета есть в конспекте, остальное дописано по стандартным учебникам |
| <span class="badge miss">нет в лекциях</span> | В конспекте этого нет, дан стандартный вариант изложения |
| <span class="badge wait">ждёт лекций</span> | Билет будет написан по учебникам, если не найдутся лекции этого года |
| ⚠️ | Расхождение между источниками или ошибка в конспекте; принят вариант лекций, если он верен |
| [неразборчиво] | В конспекте фрагмент потерян или испорчен; восстановлено по смыслу |
| «нет в лекциях, стандартный вариант» | Изложение по Шабату, Лаврентьеву–Шабату или Гурвицу–Куранту |

**Ссылки на лекции.** «С6 §2.3» — конспект 6 семестра (`sem6_lecturer_notes_LaTex_human.pdf`), раздел 2.3. «С5 §4.2» — конспект 5 семестра. «Т5-8» — билет 8 программы 5 семестра. Оба конспекта — студенческие (dmvn), курсов 2004–2005 гг.; подробности расхождений с программой 2026 года есть на странице [Карта курса](01_map.html).

## Сборка сайта

Каждую страницу:

```
pandoc X.md -s --mathml --css style.css -o X.html
```

Все сразу: `sh build.sh`. Файлы `style.css` и `site.js` должны лежать рядом с `.html`.
