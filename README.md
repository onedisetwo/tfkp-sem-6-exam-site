# ТФКП, 6 семестр: подготовка к экзамену

Сайт для подготовки к устному экзамену по теории функций комплексного переменного (мехмат МГУ, 6 семестр, программа весны 2026): 23 билета, база из 5 семестра, обзор курса, карта зависимостей, сводка формул и план подготовки.

**Сайт:** https://onedisetwo.github.io/tfkp-sem-6-exam-site/

Весь сайт собран в один HTML-файл. Его можно сохранить из браузера (Ctrl+S) и открывать без интернета: шрифты и стили встроены.

## Структура

```
site/                 исходники сайта: страницы .md, style.css, site.js, шрифты, скрипты сборки
sources/              конспекты лекций (PDF) и программы экзаменов 5 и 6 семестров
docs/
  SUMMARY.md          история проекта и принятые решения
  analysis/           разбор материалов: понятия базы, карта билетов, расхождения с лекциями
.github/workflows/    сборка и деплой на GitHub Pages
CLAUDE.md             инструкции для Claude Code (соглашения по Markdown, оформлению, источникам)
```

## Сборка локально

Нужны pandoc (проверено на 3.1.3) и Python 3.

```sh
sh site/build.sh             # site/*.md → site/*.html
python3 site/check_site.py   # битые ссылки, якоря и ошибки MathML
python3 site/bundle.py       # весь сайт → tfkp_site.html (один файл)
```

HTML-файлы генерируются и в git не хранятся.

## Деплой

При push в `main` GitHub Actions (`.github/workflows/pages.yml`) выполняет те же три шага и публикует `tfkp_site.html` как `index.html`. Если `check_site.py` находит ошибки, деплой не происходит. Перезапустить вручную: вкладка Actions → «Deploy to GitHub Pages» → Run workflow.

Один раз в настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
