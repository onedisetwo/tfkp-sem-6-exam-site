# Предлагаемая структура сайта

## 1. Файлы

| Файл | Что внутри |
|---|---|
| `index.md` | Главная: зачем сайт, как им пользоваться, кнопки на все разделы, таблица 23 билетов с отметкой покрытия ✅/◐/❌ |
| `00_base.md` | База из 5 семестра: блоки A–F (около 35 понятий), у каждого якорь `#A1` … `#F8` |
| `01_map.md` | Карта курса: SVG-граф зависимостей, таблица «билет → билеты/база», порядок изучения |
| `02_formulas.md` | Сводка формул на одну страницу (шпаргалка, удобна для печати) |
| `03_plan.md` | План на 4 дня (чт 8.10 – вс 11.10) с днём повторения; чекбоксы `- [ ]` |

Нумерация 00/01/02/03 оставлена из вашего задания; `02_formulas` и `03_plan` — мои имена, можно переименовать.

## 2. Навигация

Pandoc с `-s` не умеет общий шаблон-меню без `--template`, поэтому в начале каждого `.md` будет одинаковый HTML-блок меню (pandoc пропускает его как есть):

```html
<nav class="topnav">
  <a href="index.html">Главная</a>
  <a href="00_base.html">База</a>
  <a href="01_map.html">Карта</a>
  <a href="02_formulas.html">Формулы</a>
  <a href="03_plan.html">План</a>
  <details class="tickets"><summary>Билеты</summary> … 23 ссылки … </details>
</nav>
```

Внизу страницы билета: «← Билет n−1 · Карта · Билет n+1 →».

Ссылки между файлами — как в задании: `[Билет 5](ticket_05.html)`, в базу — `[условия Коши–Римана](00_base.html#A2)`.

## 3. Шаблон страницы билета

```markdown
---
title: "Билет 7. Области голоморфности"
---
<nav>…</nav>

> **Покрытие лекциями:** ◐ · **Источник:** С6 §2.3 · **Опирается на:** Б2, Б3, Б5, Б16

## 1. Краткий ответ на 1 минуту
## 2. Необходимые понятия            (ссылки в 00_base.html#…)
## 3. Определения и формулировки     (точно, обозначения лектора; ⚠️ где расходится)
## 4. Доказательства
### 4.1 Скелет доказательства        (3–6 пунктов)
### 4.2 Полное доказательство        (шаги + «зачем мы это делаем»)
## 5. Интуиция и картинки            (inline SVG)
## 6. Пример / типовая задача с решением
## 7. Частые дополнительные вопросы экзаменатора
## 8. Типичные ошибки и ловушки
## 9. Связи с другими билетами
## 10. Самопроверка                  (3–5 вопросов, <details><summary>Ответ</summary>…</details>)
```

Скелет доказательства ставлю **перед** полным доказательством: на экзамене сначала нужен план, а полный текст — для понимания.

Где материала нет в лекциях, раздел начинается плашкой «нет в лекциях, стандартный вариант» и указанием источника (список в `03_discrepancies.md`, §5).

## 4. Технические решения

- **Формулы:** только `$…$` и `$$…$$`, без `\newcommand`, без окружений, которые MathML в pandoc не переводит (`\begin{align}` заменяю на `\begin{aligned}` внутри `$$`). Перед сдачей каждую страницу соберу вашей командой и проверю, что pandoc не выдаёт предупреждений.
- **Скрытые ответы:** `<details><summary>Ответ</summary>` с пустыми строками вокруг содержимого, чтобы pandoc разбирал внутри Markdown и формулы.
- **SVG-схемы:** прямо в `.md` (inline), цвета через `currentColor` и CSS-переменные, чтобы картинки читались в тёмной теме и при печати. Планируемые схемы: граф зависимостей (карта); полидиск и его остов в координатах $(\lvert z_1\rvert,\lvert z_2\rvert)$ (Б 1–3); лог. выпуклость (Б 2); фигура Хартогса (Б 7); листы и склейка римановой поверхности $\sqrt z$ (Б 11–12); решётка периодов и параллелограмм $\Pi$ (Б 17–19); тор как склейка $\Pi$ (Б 20); многоугольник и отображение верхней полуплоскости (Б 22); прямоугольник для эллиптического синуса (Б 21); круговой треугольник для модулярной функции (Б 23).
- **style.css:** CSS-переменные; тёмная тема включается сама по настройке системы (`prefers-color-scheme`); липкое верхнее меню; ширина текста около 75 символов; цветные плашки для «Краткий ответ», ⚠️, «нет в лекциях»; `@media print` прячет меню, раскрывает все `<details>` и не рвёт формулы между страницами.
- **Сборка всего сайта:** `for f in *.md; do pandoc "$f" -s --mathml --css style.css -o "${f%.md}.html"; done` (это и будет `build.sh`).
