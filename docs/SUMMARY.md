# ТФКП Экзамен: сводка проекта

Перенос из Claude Projects в Claude Code, 11 октября 2026.

## Цель

Локальный сайт для подготовки к **устному экзамену по ТФКП** (мехмат МГУ, 6 семестр, лектор Белошапка, программа весны 2026). Экзамен в **понедельник 12.10.2026**. Формат: один теоретический вопрос из 23 билетов, затем опрос по определениям и формулировкам, иногда задачи.

Студент (Hasan) начинал с минимальных знаний и плохо помнит 5 семестр, поэтому на сайте есть вводный модуль «База из 5 семестра».

Полное исходное задание перенесено в `CLAUDE.md` (раздел «Задание»).

## Принятые решения

- **Обозначения лектора важнее учебников.** Если источники расходятся, используем лекции и ставим ⚠️. Таблица обозначений и предупреждений — в `site/02_formulas.md`, раздел `#f-notation`.
- **Согласованные соглашения между билетами:**
  - дискриминант $\Delta=g_2^3-27g_3^2$, он равен $D(4x^3-g_2x-g_3)/16$;
  - в Б19 голоморфная часть обозначается $h(z)$;
  - $H$ — верхняя полуплоскость в Б21–23, но фигура Хартогса в Б7;
  - в Б23 треугольник обозначается $T_1$;
  - $\operatorname{Im}(\omega_2/\omega_1)>0$; вершины параллелограмма $\Pi$ — $A,B,C,D$; $\Sigma'$ — сумма по решётке без нуля;
  - нормировка модулярной функции: $\lambda(\infty)=0$, $\lambda(0)=1$, $\lambda(1)=\infty$;
  - $\operatorname{sn}$ с периодами $4K$, $2iK'$.
- **Известные ошибки конспекта** (отмечены ⚠️ на сайте): $e_1e_2e_3=+g_3/4$ (в конспекте напечатано $-g_3/4$, Б19); в С6 формула (3) §4.1.2 путает периоды на сторонах $AB$ и $AD$; обложка С6 ошибочно называет лектором «Слепков».
- **Мероморфность** берётся по С6 §3.1.1 (полюса могут накапливаться только к $\infty$), а не по С5. Это ⚠️ 4.
- **Скелет доказательства стоит перед полным доказательством.**
- Порядок изучения в плане и на карте — по кластерам (I → III → II → IV → V → VI), а порядок написания был по номерам.
